# LUCAS Presentation

브라우저에서 실행하는 FIND ME / LUCAS 프로젝트 발표자료 초안입니다.

## 실행

```bash
cd presentation
npm run dev
```

Slidev 기본 주소는 `http://localhost:8080`입니다.

포트를 지정하려면 다음처럼 실행합니다.

```bash
npm run dev -- --port 5175
```

## 조작

- `ArrowRight`, `Space`: 다음 슬라이드
- `ArrowLeft`, `Backspace`: 이전 슬라이드
- `O`: 전체 슬라이드 보기
- `N`: 발표자 노트 보기
- `Esc`: 패널 닫기

## 내용 수정

슬라이드 내용은 `slides.md`에서 수정합니다. 발표 흐름과 세부 근거는 `storyline-draft.md`, 장표별 구성은 `slide-guide.md`에 정리합니다.
